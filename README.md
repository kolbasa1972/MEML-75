## О модели

MEML 75 — феноменологическая модель, которая описывает **фермионный
сектор Стандартной модели** (массы частиц, смешивание кварков и
лептонов, CP-нарушение) через геометрию **шестимерного орбифолда
T²/ℤ₃**.

Три поколения частиц локализованы в трёх неподвижных точках
свёрнутого бублика. Массы и смешивания определяются перекрытием
волновых функций с полем Хиггса.

## Ключевые результаты

| Блок | Точность | Наблюдаемых |
|---|---|---|
| Космология (аксион) | совпадает | 5 |
| Массы фермионов | 10⁻¹⁹…10⁻²¹ | 6 отношений |
| CKM | 0.1…5.2 % | 3 угла + J |
| PMNS | 0.3…1.5 % | 3 угла + \|J\| |

**11 независимых проверок** — все проведены. Согласованно
определено число физически независимых параметров: **14**
(6 масс + 4 CKM + 4 PMNS). Устойчивое предсказание —
**нормальная иерархия масс нейтрино (NO)**.
